## Overview
Lutealshield is a pwa intended to become a mobile app, that helps support women living with premenstrual dysphoric disorder by helping them plan for 
their hardest symptopm window(luteal phase), ground and connect in a low bandwidth manner, during that period.

## Tech Stack
Frontend: Vanilla css, javascript and type script
Backend: Python
Database: Supabase
Auth: Coming soon

## User Flow
1. Welcome to Lutealshield
2. Sign up/Sign in
3. If Sign up- then onboard
4. If Sign in-get onto homepage with phase highlighted
5. Interact with features: Bloomy, Support Cirlce, Affirmations Pocket
